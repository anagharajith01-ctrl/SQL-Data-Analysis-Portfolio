# SQL Employee Database

A MySQL project where I created a company database and wrote SQL queries to practice what I learned in my data analytics course.

## What's inside
- **3 tables:** departments, location and employees, linked using foreign keys.
- **Sample data:** 13 departments, 4 locations and 30 employees.

## What I practiced
- Creating and changing tables (CREATE, ALTER, RENAME, DROP).
- Adding rules to keep data clean (primary key, foreign key, NOT NULL, CHECK, DEFAULT).
- Getting data with SELECT, WHERE, ORDER BY and LIMIT.
- Summarizing data with SUM, MIN, MAX, AVG, GROUP BY and HAVING.
- Combining tables with INNER JOIN, LEFT JOIN and RIGHT JOIN.

## Tools
MySQL, MySQL Workbench
